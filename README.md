# Teaboom product card

Небольшой проект для тестового задания по HTML-верстке карточки товара интернет-магазина Teaboom.ru.

## Что сделано
- семантическая разметка HTML5;
- карточка товара с изображением, названием, категорией, выбором фасовки, артикулом и ценой;
- переключение фасовки без перезагрузки страницы;
- адаптивная верстка под desktop, tablet и mobile;
- кнопка «В корзину» с hover-состоянием;
- аккуратная стилизация в духе магазина.

## Запуск
Для локального просмотра достаточно открыть `index.html` в браузере.

Если нужен простой локальный сервер:

```bash
python3 -m http.server 8000
```

После запуска откройте в браузере:

```text
http://localhost:8000
```
